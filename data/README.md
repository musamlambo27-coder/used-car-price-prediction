# Data

Place the course dataset here as **`used_car_dataset.csv`**.

Expected columns: `Brand, model, Year, Age, kmDriven, Transmission, Owner, FuelType, PostedDate, AdditionInfo, AskPrice`.

`AskPrice` (e.g. `₹ 1,95,000`) and `kmDriven` (e.g. `98,000 km`) can stay in their raw text form — the notebook converts them.
